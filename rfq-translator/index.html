Frequently asked questions

RFQ Translator FAQ
What does the Alibaba RFQ Translator do?

It is a Chrome extension that translates Alibaba sourcing RFQ (Request for Quotation) detail pages from Chinese to English. It focuses on the Details section so sourcing buyers can understand inquiries from Chinese suppliers without leaving the page.

Does it translate Quantity and part numbers?

No — by design it leaves Quantity, unit, SKU, and structured specification fields untranslated. Those values stay exactly as written so there is no risk of misreading a number or a part code during quotation.

How much does it cost?

It is a one-time $1.99 purchase (via Creem or 爱发电 / Aifadian). You get 3 free translations to try it first, then a single buyout unlocks unlimited use on that device. There is no subscription.

Which browsers are supported?

The extension is built on Manifest V3 for Google Chrome and Chromium-based browsers (Edge, Brave, etc.). It activates on sourcing.alibaba.com RFQ detail pages.

Is my data private?

Authentication uses Logto, a standards-based identity provider. Translation requests are scoped to the page text you choose to translate; the extension requests only the permissions it needs to function.
